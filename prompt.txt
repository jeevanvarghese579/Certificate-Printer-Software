Data Storage Requirements (Important)
This application must be a fully client-side application.
Hosting
The application itself is hosted on Firebase Hosting only.
Firebase is used only for serving the website.
Do NOT use:
Firestore
Realtime Database
Firebase Authentication
Firebase Storage
Any backend server
Any cloud database
User Data Storage
All user-created data must be stored locally in the user's browser using LocalStorage (or IndexedDB if needed for large templates).
Store locally:
Student records
Categories
Imported CSV data
Certificate templates
Uploaded images used in templates
Dynamic field positions
Page setup settings
Theme preferences
Application settings
Undo/Redo history
Privacy
No student information is uploaded to any server.
No student information leaves the user's device.
All certificate generation happens in the browser.
PDF generation happens locally.
JPEG generation happens locally.
ZIP creation happens locally.
Offline Support
